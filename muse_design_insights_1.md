# Design Insights for the Paper Build — distilled, builder-actionable

Jeremiah's directive (2026-09-24): **no more questions to him — we decide, we build, he judges the paper.** Everything below is decided direction, not a proposal awaiting approval.

## 1. Anti-slop (the highest law)

Slop is the **absence of decisions**, not the presence of errors. Every element on the page must have a reason it exists. Instant-fail tells — if any of these ship, the build is wrong:

- Yellow/oversaturated image grade, giant outlined display letters, paint swashes or glow effects
- Default indigo/violet (`#6366f1`) anywhere
- Blob backgrounds, frosted-glass blur, faux wood/paper texture overlays
- Icon-per-bullet clutter, cookie-cutter card grids
- Decorative orange — orange/amber is **live data, controls, and alerts only** (the moving thing gets the warm color; everything else stays restrained)
- More than one heritage device per spread (pick ONE per edition: the drop cap, the double rule, the steel frame — never all three at full volume)
- A page that could belong to anybody

Each edition names a **style anchor** (a movement, not a vibe — e.g. `STYLE ANCHOR: BERLINER MODERNISM / BAUHAUS GRID`) in the colophon. Full commitment reads as voice; half-quirk reads as template.

## 2. Composition steals (web / magazines / ads)

- **One signature interaction per page.** Not five micro-delights — one moment the reader remembers (ours: the "develop," image resolving like a photographic print).
- **One accent color, spent like ammunition.** Jeremiah's palette: plaster `#EDE6D6`, warm stone `#A69B8B`, teak `#8A5A2B`, brushed steel `#8E9299`, box red `#ED1C24`, safety orange `#FF5C00` (controls/alerts only), ink black `#16130E`.
- **Chromatic chapters, not rainbow sectioning.** Sections get treatments (Field Notes = raking-light grade, Ledger = machined steel, Notice Board = zine layer), not each their own hue.
- **The index itself can be the front-page design.** The Site Plan TOC is a design object, not a menu.
- **Empty space is the serious register.** Whitespace is active material — when the story is grave, the page gets quieter, not louder.
- **Special editions get one production-level gesture** (a livery, a crushed masthead, gilt-edge rules) — never just a redecoration.
- **One recurring conceptual image per edition** carries the thesis; everything else is supporting.

## 3. Build-like-an-engineer rules (architecture / auto / nature)

- **The Banham test:** the page must be memorable as an image, visibly structural, and use materials honestly. No fake textures, no pretending.
- **One recurring signature device** — the double-rule steel frame around nature heroes is our "yellow border." Repeat it until it's trademark.
- **One hero number per data surface.** In Cross Section and the Ledger, each module gets exactly one enormous numeral + a tiny mono label. Dense typography is fine; competing big numbers are not.
- **Captions are journalism; credits are design.** Every image teaches something non-obvious (behavior, mechanism, stakes) and carries a visible credit line, always.
- **Alternate named treatments, don't blend.** Paper mode and ink mode are each designed natively — never one theme with inverted variables.
- **The system must survive tired, imperfect implementation.** If a section only looks right when perfectly executed, it's the wrong design. Build the version that still looks intentional on a bad day.
- **Obsessive subject knowledge becomes an aesthetic.** Spec-sheet density, real terminology, exact numbers — precision reads as style.

## 4. Voice on the page (for whoever writes strings)

- Kicker is the playground, headline is the professional. Never a pun on tragedy — breaking news goes quiet, not loud.
- One wit per screenful, max. No exclamation points outside the Notice Board.
- Facts wear mono; voice wears serif. Data never jokes; the section name does.
- The reader is a modern, stylish, intelligent man who notices kerning and materials. Never talk down, never hype.

## 5. The merge gate (already agreed — repeating so it's in one place)

A build doesn't ship to preview if it trips any of these: no named style anchor; decorative orange; more than one heritage device; frosted blur or faux grain; more than two surface treatments per card; uncredited or ungraded photography; body measure wider than 75ch; cookie-cutter grids; default indigo; blob backgrounds; giant outlined type; yellow grade; a page that could belong to anybody.
